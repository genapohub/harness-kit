## 一、AI 功能集成四种推理模式（先选模式再动手）

| 模式 | 适用 | 延迟要求 | 实现要点 |
|------|------|----------|----------|
| **实时（Realtime）** | 聊天/问答/即时分析 | <100ms | 同步 API，负载均衡 + 自动扩缩 |
| **批量（Batch）** | 大数据集离线处理 | 分钟级 | 异步队列，断点续跑 |
| **流式（Streaming）** | 持续数据/事件流 | 秒级 | 事件驱动，背压处理 |
| **边缘（Edge）** | 隐私/离线/低延迟 | 设备端 | 模型压缩 + 端侧推理 |

> 后端设计决策顺序：**先定推理模式，再定架构**——实时走同步 API、批量走任务队列，混用会两头不讨好。

## 二、模型生产化生命周期（不是"训完就完"）

```
数据准备（采集/清洗/校验/特征工程）
  → 模型训练（算法选择/超参调优/交叉验证）
  → 模型评估（性能指标 + 偏差检测 + 可解释性）
  → 模型验证（A/B 测试 + 统计显著性 + 业务影响）
  → 生产部署（版本化 + API + 监控告警）
  → 线上监控（漂移检测 + 自动重训触发）
  → 优化循环（成本/延迟/精度持续改进）
```

**关键纪律**：模型是"会过期"的代码——生产监控（漂移检测/数据质量/推理延迟）不是可选，是生命周期的一部分。

## 三、AI 伦理与安全基线（合规底线，非可选）

- **偏差检测**：跨人口群体跑公平性指标（bias testing），不只是整体准确率
- **隐私保护**：差分隐私 / 联邦学习；数据脱敏（呼应 SECURITY.md）
- **可解释性**：XAI 技术提供模型可解释性；关键决策保留人工 oversight（呼应 AGENTS.md"AI 不拍板"红线）
- **内容安全**：对抗鲁棒性测试 + 危害防护——AI 功能必须有输出安全层，尤其 UGC/对话类

---

## 四、LLM/RAG 集成要点（SaaS 最常见需求）

- **向量库选型**：Pinecone/Weaviate/Chroma/FAISS/Qdrant，MVP 场景 PostgreSQL+pgvector 优先（见 mvp-architect 蒸馏）
- **LLM 接入**：OpenAI/Anthropic/Cohere + 本地 Ollama/llama.cpp（敏感数据走本地，呼应 SECURITY.md 模型路由）
- **评估先行**：每个 LLM 功能定义成功指标（准确率/拒答率/幻觉率），上线前跑评测集（呼应 qa 蒸馏"评测驱动交付"）

## 五、AI 后端成功指标（量化基线）

| 指标 | 目标 |
|------|------|
| 模型精度 | F1/准确率 ≥85%（达业务要求） |
| 推理延迟 | 实时应用 <100ms |
| 服务可用性 | >99.5% + 错误处理 |
| 单次预测成本 | 预算内（模型压缩/高效推理优化） |
| 漂移检测 | 自动重训触发可靠 |
| AI 功能效果 | 用户参与度提升 ≥20%（典型目标） |
