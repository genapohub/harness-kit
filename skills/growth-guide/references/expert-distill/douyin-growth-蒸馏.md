## 一、北极星指标定义（Step 0）——先定"优化什么"再动手

> 没有北极星，所有增长动作没有统一衡量标准。"涨粉/互动/爆款"都是中间指标，不是最终增长目标。

**按业务阶段选北极星**：

| 业务阶段 | 候选北极星 | 理由 |
|---------|-----------|------|
| 冷启动期（新用户 <1 万） | 周均激活率 / 首批完成核心行为用户数 | 验证 PMF 优先 |
| 成长期（1-50 万） | 月均单用户有效互动量（加权） | 验证留存与粘性 |
| 成熟期（50 万+） | 7 日新用户留存率 / 传播深度（分享/内容比） | 验证健康度 |
| 变现期 | 单用户商业价值 / 付费转化率 | 验证商业模型 |

**输出四要素**：选定指标 / 当前基线（带数据来源）/ 目标（用户期望或行业基准）/ 选择理由（基于业务阶段分析）。

**纪律**：后续每个策略建议必须回链北极星——推不动北极星的策略要么解释为什么仍值得做（基础建设），要么降级优先级。

## 二、增长实验设计（Step 4 内核）——7 要素模板，非排期表

> 排期表只回答"哪天发什么"；增长实验回答"为什么做、怎么验证、失败怎么办"。**内容日历升级为假设驱动的实验设计**。

每个实验必须含 7 要素：

| 要素 | 必填 | 示例 |
|------|:---:|------|
| **假设** | ✅ | "如果引入 X 变量，互动率将从 1.5% 提升至 3%" |
| **变量** | ✅ | 单一变量，一次只测一个（变量交叉 = 实验报废） |
| **对照组（基线）** | ✅ | 当前常规方案 |
| **实验组** | ✅ | 改变变量后的方案 |
| **成功标准** | ✅ | 可量化阈值（如"互动率 > 2.5%"） |
| **样本量** | ✅ | 每组至少 2-3 个样本，保证结果可信 |
| **执行周期** | ✅ | 建议 2 周一轮 |

**实验编排纪律**：
- 同一时间只跑 1-2 个实验，避免变量污染
- 实验组/对照组**同时间段交替发布**（避免时间偏差）
- 优先级：P0（直接推动北极星）→ P1（间接）→ P2（探索）

**结果分类**：✅ 假设成立（放大） / ⚠️ 方向对幅度不够（调阈值） / ❌ 假设不成立（回头查数据找原因，不硬凹）。

## 三、归因的替代假设检验矩阵（Step 2 内核）——反拍脑袋核心工具

> 关键纪律：**任何归因结论（如"衰退原因是 X"）前，必须排除替代假设**。未经检验的归因必须标注"置信度：低"。

| 替代假设 | 检验方法 |
|---------|---------|
| **平台/算法调整？** | 检查同赛道其他玩家是否同样下降 |
| **季节性波动？** | 对比去年同期趋势（暑假/春节/大促节点） |
| **节奏偏移？** | 对比高低谷期的发布频次/时间分布 |
| **内容质量本身变化？** | 逐条对比标题/结构/核心要素使用频率 |
| **平台政策/限流？** | 检查账号诊断信号 |
| **竞品/替代分流？** | 看新爆发的同类账号 |

**输出格式**：假设 × 检验结果 × 排除？（✅/❌）× 数据来源 的矩阵，然后给"排除 N 个假设后，最可能归因是 X，置信度：高/中/低"。

> 此工具适用于**一切业务指标的归因分析**（不只是内容平台）——转化率掉了先跑矩阵，别急着怪某一个原因。

## 四、增长漏斗估算与漏水节点（Step 6 内核）

**通用漏斗估算框架**（每环节标注估算依据 + 置信度）：

```
用户进入
  ↓ 估算激活率 = 完成核心行为用户 / 进入用户
激活
  ↓ 估算互动/使用率 = 活跃用户 / 激活用户（精确数据优先）
留存/使用
  ↓ 估算分享率 = 分享量 / 互动量
传播
  ↓ 估算转新率 = 新增用户 / 分享总量
拉新
```

**漏斗分析三问**：
1. 哪一步"漏水"最大？（转化率最低的环节）
2. 这个环节由什么内容/产品特征造成？（回链内容归因）
3. 针对这个环节的下一步实验方向？

**传播健康度基准**（分享/互动比）：
- > 15%：🔥 病毒传播潜力强
- 8-15%：📈 健康传播
- < 8%：📉 传播乏力，"叫好不叫传"

## 五、数据纪律 11 条（反AI味 · 强制）

1. **不编造数据**——所有数据来自实际工具/埋点调用，失败就如实说，不凭空填充
2. **估算必须标注**——每个估算值用 ⚠️ 标记 + 估算方法；不可得维度明说"数据不可得"，不跳过不暗示
3. **不替代用户判断**——用"建议/推荐"，不用"你必须"；最终决策是用户的
4. **结论先行**——每个分析先给 1-2 句核心结论，再展开细节
5. **建议必须可执行**——不说"可以优化内容"，说"将 X 从 A 改为 B，周期 C，预期 D"
6. **引用来源**——引用数据标来源（"数据来源：X 月榜单"）
7. **增量交付**——复杂分析分阶段输出，每步确认方向再继续，避免一次过长
8. **时效性提示**——数据有时间窗口，引用时说明范围
9. **交叉验证**——同一结论尽量两个以上数据源支撑
10. **先数据后结论**——每个环节先拿数据再推演，不凭空推理
11. **术语可读性**——专业术语首次出现用括号附白话解释；报告是给用户看的，不是给同行看的

## 七、蓝海定位量化法（Step 3 内核，半通用）

```
需求热度   = 该细分方向的上榜作品数 × 平均互动量（需求信号）
竞争密度   = 该方向的上榜玩家数 × 头部规模均值（供给信号）
蓝海指数   = 需求热度 / (竞争密度 + 1)
```
- 指数越高 = 需求相对竞争越旺盛
- 定位输出：竞争格局分层（头部/追赶/新机会）+ 差异化切入点建议（至少 3 个具体空白）
- ⚠️ 蓝海指数是相对估算值，只反映"已上榜内容"的供需，不覆盖长尾
