## 三、Harness 迭代项（N1-N9 → AGENTS.md v1.3 / 工作流）

| 编号 | 迭代项 | 落地 |
|---|---|---|
| **N3（最高优先）** | **多会话并行纪律**：同一仓库同一时间只允许一个 agent 会话；开工前 `git log -1` 确认基线、`git status` 确认干净；发现与预期不符的外部改动立即停下向人类确认；开工前先 `git log --all --oneline` 查是否已有同类实现 | AGENTS.md 第五部分新增 |
| **N4** | **多仓库操作纪律**：每个工作块开头 pwd 确认仓库；commit 前 `git branch --show-current` + `git status` 双确认；批量多仓库操作封装为脚本而非裸 cd 链 | AGENTS.md 第五部分新增 |
| **N6** | **写文件规范**：禁止多条 heredoc 拼接写多文件（边界错位风险），用 Write 工具或单 heredoc 单文件+行数验证 | AGENTS.md 第五部分新增 |
| **N5** | **合并授权语义**：人类"继续开发"≠ 免 review 合并；连续任务序列合并需人类明示"连续模式"（合并后仍需事后 review 可 revert） | AGENTS.md 第二部分主导级别注释 |
| **N9** | **review 标准动作** = 可操作链接（哥拿坡已定）：起本地服务给 localhost 地址，服务由人类手动管理 | 已入记忆 ✓ |
| **N1** | **命名前置**：品牌/项目命名是独立设计任务（设计师决策），技术代号用中性名（代号不承担品牌语义），避免改名连锁 | 经验沉淀 |
| **N2** | **定位变更流程**：影响评估（波及文档/代码清单）→ 人类拍板 → 一次性执行；设计存档不删除 | 已实践 ✓ 固化 |
| **N7/N8** | **测试断言用真实业务值**（如金额累加 800 而非 640）+ 口径在实现前注释声明 | 经验沉淀 |
